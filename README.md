重庆，江北嘴。你接手渝江证券——一家一九九三年成立的本地小券商，全国排名第九十六。牌子还在，客户还在，就是不挣钱。手续费收入比二〇一五年少了一个零，账上八个亿，按现在的亏法能撑四年。

股东方换了董事长，董事长空降了你。任期三年，三十六个月。

## 这三年里会发生什么

行情是主角。冷清、回暖、疯牛、股灾、修复，每一局都完整走一遍，但什么时候转、转多狠，每局都不一样。牛市里营业部排队排到楼下；股灾里两融爆仓、大户骂娘、董事会问责。你在顶点做的那个决定，决定你能不能活过后面五个月。

托管在你这儿的三百亿是客户的，一分都不是你的。你能拿的只有佣金、尾佣、利息和承销费。

来钱快的路子都留案底。年底有分类评级，掉一级就是业务资格没了。

七个人各有各想要的东西：董事长要业绩更怕出事，老营业部的客户比公司还认他，投行想做出一单证明自己，自营怕亏更怕踏空，合规什么都留痕，研究想上热搜，大户室的阿姨坐了十八年。

十一个结局，二十一个成就，十二个天赋，三个挑战模式。同一个种子必然复现同一轮牛熊。
