# 模拟券商 · 渝江证券经营手记

**[线上版本](https://lynch715.github.io/broker-sim/)**

重庆，江北嘴。你接手渝江证券——一家一九九三年成立的本地小券商，全国排名第一百二十五。牌子还在，客户还在，就是不挣钱。手续费收入比二〇一五年少了一个零，账上三亿五千万，收入还盖不住开支。

股东方换了董事长，董事长空降了你。普通模式可选三年、六年或十年，默认十年；旧存档可在设置中延长。挑战模式保留各自期限。

## 经营路上

行情是主角。冷清、回暖、疯牛、股灾、修复，每轮三年走过一遍，长任期会继续经历新的周期，但什么时候转、转多狠，每局都不一样。牛市里营业部排队排到楼下；股灾里两融爆仓、大户骂娘、董事会问责。你在顶点做的那个决定，决定你能不能活过后面五个月。

托管在你这儿的一百二十亿是客户的，一分都不是你的。你能拿的只有佣金、尾佣、利息和承销费。

来钱快的路子都留案底。年底有分类评级，掉一级就是业务资格没了。

七个人各有各想要的东西：董事长要业绩更怕出事，老营业部的客户比公司还认他，投行想做出一单证明自己，自营怕亏更怕踏空，合规什么都留痕，研究想上热搜，大户室的阿姨坐了十八年。

十一个结局，二十一个成就，十二个天赋，三个挑战模式。同一个种子必然复现同一轮牛熊。

## 怎么玩

网页直接开，手机也行。Safari 里「分享 → 添加到主屏幕」可以当 app 用，全屏启动。进度自动存在浏览器本地。

## 仓库里是什么

| | |
|---|---|
| `index.html` | 整个游戏的代码与界面，约0.6MB（传输压缩后约0.22MB）。不依赖任何 CDN、框架或外部字体 |
| `assets/` | 运行时美术：33张场景/结局/人物图与40张员工头像，文件名带内容摘要。**发布时必须和 index.html 一起上传** |
| `sw.js` | 离线缓存。由 `tools/build-sw.py` 生成，改过 index.html 或 assets/ 后重跑一次 |
| `icon-*.png` / `apple-touch-icon.png` / `manifest.webmanifest` | 添加到主屏幕用的图标和配置 |
| `docs/` | 设计稿、施工规范、各阶段交付说明、配色和适配记录 |

本轮以当前仓库的 `index.html` 为实际修改入口，并同步 `模拟券商.html`。纸墨样式留有 `styles/paper-broker.css`，运行所需样式和图标仍内嵌于 HTML。

本轮增加六类长期建设、三级升级、经营方式和年度经营重点，后续年份继续刷新投行候选。设置页提供主题切换和作者联系方式。详见 [本轮交付说明](docs/18-纸墨经营与十年任期.md)。

## 一点说明

游戏里的公司、人物、事件全是虚构的。业务逻辑参照真实的证券公司经营框架——经纪、代销、两融、投行、自营、研究所、分类评价——但数值是为了好玩调的，不是行业真实水平，别拿来做任何判断。
