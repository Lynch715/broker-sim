# 员工培训与状态节奏（2026-10-30）

修改入口：`index.html`，同步 `模拟券商.html`，并重新生成离线缓存 `sw.js`。本轮改动限定为员工培训与状态节奏。

## 培训

「员工」页和「抓内部」菜单均可进入。营销实训、管理研修、风控进修分别培养对应能力：每次消耗1精力，费用为30＋当前星级×20万（50～110万）。每人每月一次，每次积累50进度；同方向两次升一星，上限五星，升星后月薪增加0.3万。挖人时已有的薪酬溢价保留。每次培训另有员工倦怠-6、公司士气+2，均受0～100边界限制。

不同方向分别保存进度。当前进度、培训月份、升星能力与工资随员工存档保存；旧档自动补齐空的培训档案，原有月份、金额、身份、能力和倦怠不重置。新招聘、挖人和剧情回归员工也可直接培训。菜单展示报价，执行时重新核验现金、精力、月份和能力上限；月末处理中不能安排。

## 状态调整

- 日常工作负担：空闲骨干2、主任4（原5、8）；正常休息每月抵消2。
- 网红特质额外负担从4降为2；老股民额外减1；大会战额外从3降为2；极热行情额外从4降为2。管理均星超过3后继续抵消负担，最多再抵消1；坚韧天赋仍降低正向倦怠增长。
- 开局正常月份：冉建国每月+1（原+6），陈斌+4（原+12），唐蕾+0（原+5）。事件、营销行动仍可增加倦怠。
- 轮休立即恢复24倦怠（原14），士气+6（原4），月末额外减负8（原6）。保留营业部当月产出×0.75，每月只可安排一次。
- 士气基准改为45＋口碑×0.22＋管理均星×2－平均倦怠×0.15，自营满仓亏损压力仍为-6。每月向基准靠拢12%，自然回落最多2.5、回升最多3。欠薪、辞退、事件等直接影响保留。
- 员工卡持续显示倦怠、预计月末变化及三类培训进度，低倦怠也能看见数值。
