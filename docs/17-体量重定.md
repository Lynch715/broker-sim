# 17 · 体量重定：从三百亿缩到一百二十亿

> 2026-09-13。Lynch 问「一个末流券商的区域总部管理的资产这么高吗」，查了实际数据之后重做。

## 查到的数

- 全行业 2024 年末为 **84.1 万亿**客户资产提供交易托管服务，约 150 家券商。
- 中信 12 万亿（1580 万客户）、银河 5.09 万亿（1730 万客户）、申万宏源 4.75 万亿、招商 4.27 万亿、中金 3.18 万亿。
- 第 20 名上下：中泰 1.36 万亿、光大 1.37 万亿、东方证券 8783 亿。
- 只有 **33 家**券商的代理买卖证券业务净收入超过 10 亿。
- 全行业营业部 **11783 家**，银河一家 461 家，平均 80 家一户券商。
- 华林证券（中小，75 家营业部）两融余额只有 57 亿。

**单家营业部托管多少**：全行业平均 71 亿（84.1 万亿 ÷ 11783）；银河 108 亿一家（它是营业部最多、最零售的那家）；招商 170 亿一家。这些是头部，里面含机构客户和网上开户挂靠的资产。末流券商的营业部没有这些，一家二三十亿是常态，位置好、有大户室的能到五十亿。

**结论**：三个营业部的公司，真实体量是 80–150 亿，不是 300 亿；而且这个体量在 140 家里排 120–135 名，不是 96 名。两个数是绑在一起的。

## 改了什么

```
客户资产   300 亿 → 120 亿      解放碑 60 / 观音桥 35 / 沙坪坝 25
基金保有    20 亿 → 8 亿
开局排名    第 96 → 第 125
军令状      三年进八十 → 三年进一百
```

成本也跟着缩到这个体量该有的水平——不缩的话开局月亏从 200 万变成 392 万，董事长 52.8% 把人换掉：

开局对账：月收入 183 万（经纪 150 + 代销 33），月成本 325 万，月亏 142 万。六个月固定开支 1951 万——这条线是自营加仓和两融融出的闸门。

## 连带要改的三处引擎

**一、排名公式又要重拟。** 实力分 = 客户资产（亿）×0.5 + 年化收入（亿）×20 + 评级加减分。客户资产从 300 亿缩到 120 亿，实力分从 150 掉到 60，常数和斜率都得重定：`8 + 132·exp(−(adj−50.6)/78)`，开局正好第 125 名。斜率从 106.6 收到 78，是因为在新体量下客户资产的绝对变动小了，不收窄的话排名对经营根本不响应。

**二、评级加减分整体缩一档。** 原来 AA +60 / B −60 / C −160，是照着实力分 150 的量级定的。在实力分 60 的体量下，B 级的 −60 直接把实力分清零，公司必掉到第 140 名——这就是重定之后「牌子没了」一度飙到 24% 的原因。现在是 AA +26 / B −26 / C −72 / D −90。

**三、「牌子没了」的门槛是写死的 `rank > 110`。** 开局就是第 125，这条线等于「没垫底也算被吞」。改成 `rank > 开局排名 + 14`。

另外董事长那条「累计利润为负就扣分」删了——在这个体量下累计利润结构性为负（一次性投入占比更大），这条每季度都触发。只留最近六个月的经营损益那条，阈值也从 0.6 倍六月成本放宽到 1.0 倍。

## 顺手修的一个真 bug

⑤ 把自营改成真金白银划转之后，事件里还有十来处 `S.prop = 2` 直接改档位——不走 `propMove()`，钱不动。罗劲要额度的三幕、他离职的三处、挑战模式里各有一处。全部改成走 `propMove()`。这个 bug 的效果是：玩家在事件里答应加仓，自营账户是空的，涨了不赚跌了不亏。

## 重新校准（随机策略 400 局）

| 指标 | 结果 | 目标 |

| 存活率 | 58.3% | 50–60 ✓ |
| 风险处置 | 19.5% | 15–22 ✓ |
| 董事会换帅 | 14.2% | 15–20（差 0.8） |
| 平稳交班 | 40.3% | 25–35（超 5） |
| 路线结局合计 | 18.0% | 12–20 ✓ |

| 股灾期客户净流出 | −12.0% | −8~−14 ✓ |

平稳交班还是超，原因跟 16 号文档里写的一样：存活率 = 平稳 + 路线 + 隐藏，三个区间数学上互斥。

路线目标里两条跟着体量重定了：投研的分仓累计从 1.6 亿改成 9000 万（perStar 从 120 砍到 70，原来的门槛达成率 0%）；稳健从「评级没掉到 BB 以下」改成「案底 0，三年一张罚单都没有」（原条件 6%，低于下限，而且新体量下评级本来就低）。

## 文案

开场说明、上任第一天、军令状、五条要点、路线选择页、银行柜台那条事件、罗劲要额度的三幕、爆款基金那条——所有写死「三百亿」「第九十六」「进八十」「自营池十个亿」「三个亿的额度」的地方都改了。开场那段重写过：

> 账上有三亿五，看着还能烧几年。但这笔钱是公司的全部家当——自营要用它，两融要用它，开一家营业部就是五千万。真正能躺着亏掉的，没有那么多。
