## 〇、对 Codex v0.1 稿的处理

保留：山城背景、36个月×3点精力的骨架、"客户的钱不是公司的钱"这条红线、投行分阶段收费、自营买入不是费用这几条对账原则。

不要的：

- 两个"资产池"、capitalLoad、"综合服务费率"这套词。玩家不是来学会计的。
- 事件写成合规培训材料（"一张风险测评""降薪表上的签字"）。券商人的日常不长这样。
- 六个人物只有履历表，没有一句像人说的话。
- 行情被做成了一张"换手倍数表"。行情是券商游戏唯一的主角，得让玩家眼睁睁看着它涨、看着它跌。
- 虚构的"江州"。银行版在地感是最大资产，这作直接落在重庆，公司虚构，地名真实。

一句话概括改法：**把"券商的四门业务"换成"券商人的三年"。**

## 一、这游戏凭什么比《模拟银行行长》好玩

银行版的存款是慢变量，三年是平的，靠事件和人撑着。券商不一样：

1. **行情是主角，三年必有一轮牛熊。** 每局都会经历 冷清→回暖→疯牛→股灾→修复。牛市来的时候营业部排队开户、系统宕机、全员发财；股灾来的时候两融爆仓、大户骂娘、自营腰斩、董事会问责。同一个玩家在牛市顶点的决定，决定他能不能活过股灾。这是银行版没有的"过山车"。
2. **有集体角色——散户。** 股吧每个月都在评论你这家券商。你降佣金、你宕机、你吃罚单，股吧都知道。
3. **诱惑比银行大得多。** 从业人员不能炒股，但你天天看着客户挣钱；配资、老鼠仓、吹票、给企业造假打掩护，每一条都来钱快，每一条都留案底。
4. **年终有一张"成绩单"：分类评级。** 证监会每年给券商打分（AA/A/BBB/BB/B/C），掉一级业务资格就没了。比银行的排名更狠、更真。
5. **同行会整建制挖人。** 营业部老总带着团队和客户一起走，是券商特产。

## 二、世界与人物

### 2.1 设定

重庆。你接手**渝江证券**——一家 1993 年成立的本地小券商，全国排名 96/140 左右，总部在江北嘴，最老的营业部在解放碑，大户室里坐着从认购证年代活到今天的阿姨。牌子还在，客户还在，就是不挣钱。股东方（市里一家国企）换了董事长，董事长空降了你。任期三年。

开场：

> 许伯衡把去年的报表推过来，没说话。
> 报表上手续费收入那一行，比 2015 年少了一个零。
> 窗外嘉陵江起雾。手机震了一下，是解放碑营业部的冉建国：
> 「秦孃孃要把三千万转到隔壁去，说人家佣金万一。您先见她，还是先开会？」

### 2.2 玩家

渝江证券总经理。不设姓名性别，不要"空降背景"选项，开局天赋（二周目）承担这个功能。

### 2.4 集体角色：股吧

- 你宕机了：「渝江又崩了，我的涨停板没了，退钱！」
- 你降佣到万一：「渝江万一了，隔壁还万二五，转户教程有吗」
- 吃罚单：「证监局都点名了，这种券商还敢开户？」「点名怕啥，哪家没吃过」

- 贺予非喊高点：「渝江首席说 8000 点，我信了，然后呢」

股吧不影响数值，只反映数值。每月 3–5 条，成本极低，世界感回报最高。

## 三、一个月怎么玩

节奏同银行版：**36 个月 × 每月 3 点精力**。

界面五块（复用银行版布局）：

1. **顶栏**：第 N 月 · 大盘（点位+当月涨跌）· 情绪温度计 · 精力
2. **六张指标卡**：现金 / 客户资产 / 口碑 / 士气 / 风险 / 行业排名
3. **六个行动**（花精力）：跑业务 · 走关系 · 抓内部 · 投行项目 · 自营调仓 · 扩张
4. **面板 Tab**：营业部 · 员工 · 关系 · 项目 · 自营 · 日志
5. **月底结算 → 月报 →（事件/主线/对手）→ 下月**

一个不花精力的重要开关放在营业部 Tab 顶部：**佣金率拨盘**（万2.5 / 万2 / 万1.5 / 万1），每月可调一次。降佣金当月开户就多、收入就少，且**降下去容易升上去难**（升佣会流失客户）。这是券商版的"高息揽储"。

行动菜单：

| 行动 | 子项 | 精力 | 效果（种子数值，进 BALANCE） |
|---|---|---|---|
| 🏪 跑业务 | 跑银行驻点开户 | 1 | 客户资产+（受情绪温度计放大）、口碑+1 |
| | 开户大会战 | 1 | 客户资产++、全员倦怠+8、士气−3，季度限一次 |
| | 冲基金代销 | 1 | 现金+（一次性）、基金保有+；牛市顶部冲会埋雷（股灾后投诉） |
| 🍶 走关系 | 七人任一 | 1 | 好感+按偏好 6/3；秦孃孃只能"拜访"，不能送礼 |
| 📋 抓内部 | 团建 / 合规排查 / 轮休 / 招聘 | 1 | 同银行版；合规排查 风险−6，且是唯一能"处理"案底的动作（见第七节） |
| 📄 投行项目 | 接项目 / 尽调 / 推进 | 1 | 见第六节 |
| 📈 自营调仓 | 空仓 / 半仓 / 满仓 | 1（罗劲≥60 免费） | 见第六节 |
| 🏗 扩张 | 开营业部 / 升级交易系统 / 建研究所 | 1 | 开营业部现金−、月租+；系统升级决定疯牛期会不会宕机 |

免费动作：看日志、看人物、调佣金、看项目详情、看股吧。

## 四、经济模型（少而清楚）

内部单位统一**万元**，显示大数用亿（一位小数）。

### 4.1 状态量

```
cash        自有现金（万）        开局 80,000（8亿）
aum         客户资产（万）        开局 3,000,000（300亿），随大盘估值+净流入
fundHold    基金保有（万）        开局 200,000（20亿）
margin      两融余额（万）        开局 0，P1 解锁
prop        自营档位 0/1/2        空/半/满，自营池上限 = 100,000（10亿）
index       大盘点位              开局 2,900
mood        情绪温度计 0–100      开局 35
fee         佣金率档 0..3         万2.5/万2/万1.5/万1，开局万2.5
trust/morale/risk  0–100         开局 55/60/20
rank        行业排名              开局 96
grade       分类评级              开局 BBB
dirt        案底（隐藏）           0
xuPatience  董事长耐心            = 许伯衡好感，不单设
```

### 4.2 月收入

```
经纪收入 = aum × 月换手 × 佣金率
   月换手由情绪决定：冰点0.3 观望0.5 回暖0.8 亢奋1.4 疯狂2.2
   佣金率：万2.5=0.00025 ... 万1=0.0001
   冷清期算例：300亿 × 0.4 × 0.00025 = 300万/月
   疯牛期算例：480亿 × 2.0 × 0.0002 = 1920万/月
代销收入 = fundHold × 0.5%/12 + 当月冲销一次性
两融利息 = margin × 8%/12   （300亿×5%渗透→1000万/月，疯牛期的第二桶金）
投行收入 = 项目里程碑到账
自营损益 = 自营池 × 档位/2 × (大盘涨跌 × 1.2 + 罗劲alpha)   → 直接进 cash
研究所   = 建成后 分仓佣金 每月 80万 × 贺予非星级
```

### 4.3 月成本

```
固定成本 = 总部 350万 + Σ营业部月租 + Σ员工月薪
系统维护 = 交易系统等级 × 30万
两融资金成本 = margin × 4%/12
罚单/赔付 = 事件产生
```

开局无事：收入约 300+80 = 380 万，成本约 350+120（解放碑等三家）+90 = 560 万，**月亏 180 万**。8 亿现金能亏四年，所以破产不是主要压力；压力来自董事长耐心、排名、分类评级。这跟银行版"存款焦虑"不同，是"你到底靠什么挣钱"的焦虑——直到牛市来。

### 4.4 客户资产怎么动

```
月末 aum = aum × (1 + 大盘涨跌 × 0.7)      ← 估值，不算你的本事
          + 净流入                           ← 才算你的本事
净流入 = 基础流入(情绪) + 行动 + 佣金档位效应 + 口碑效应 − 对手挖客 − 事件
```

结算和传记里"客户资产增长"只算净流入累计，浮盈不算——不然牛市里人人都是经营之神。

### 4.5 排名

行业 140 家，用一个简化的"实力分"排：`aum×0.5 + 年化收入×20 + 投行完成数×2000万 + 评级加成`。每季更新，显示在指标卡上，带 ↑↓。牛市里所有券商都涨，排名靠**相对**——你比同行多开了几个户。

## 五、大盘与周期（本作核心）

### 5.1 36 个月剧本

| 阶段 | 月份（基准，边界各抖±2） | 大盘月涨跌 分布 | 情绪走向 | 现实对照 |
|---|---|---|---|---|
| 冷清 | 1–8 | 均值 −1%，σ 4% | 冰点→观望 | 三千点保卫战 |
| 回暖 | 9–14 | +3%，σ 4% | 观望→回暖 | 成交量放大，同业群开始转发研报 |
| 疯牛 | 15–20 | +9%，σ 7% | 亢奋→疯狂 | 排队开户、大妈进场、券商股旗手、宕机 |
| 股灾 | 21–25 | −12%，σ 9% | 疯狂→冰点 | 千股跌停、强平、配资爆仓 |
| 修复 | 26–36 | +1.5%，σ 5% | 冰点→观望→回暖 | 追责、合并潮、谁还活着 |

每局必有一轮完整牛熊。种子决定抖动和幅度（疯牛涨幅 60%–140% 之间，股灾跌幅 30%–50%）。大盘走势用 canvas 画一条 36 月折线放在顶栏，玩家能看着它爬、看着它塌。

### 5.2 预兆

每次切换前 1–2 月，月报里出现一条"同业消息"（复用银行版 CYCLE_NEWS 机制）：

- 回暖前：「营业部说这个月来开户的，有三个是问『现在还能不能进』的。四年没人问过这句话。」
- 疯牛前：「贺予非的研报被转了两万次。标题是《牛市的起点》。他自己都没想到。」
- 股灾前：「监管开始查场外配资。罗劲说没事，去年也查过。沈清禾把纪要复印了三份。」
- 修复前：「同业群里有人发了个红包，没配文字。三分钟后有人回：『还活着的报个数。』」

预兆只说方向，不说点位。

### 5.3 牛市三部曲（每局必发的脚本事件）

不是随机事件，是按阶段进入自动触发的主线，三幕跨六个月：

**第一幕·开户潮（疯牛第 1 月）**
解放碑营业部排队排到楼下。系统等级 1 的话，第二幕必宕机。选项：临时加人（现金−，客户++）/ 限流（口碑−，稳）/ 让冉建国带人去银行门口摆桌（客户+++，倦怠+++，风险+4 因为流程不合规）。

**第二幕·九点二十七分（疯牛第 3 月，系统≤1 级必触发，2 级 40%，3 级不触发）**
交易系统崩了 40 分钟。股吧炸锅。选项：连夜换系统（现金−800万）/ 赔付客户（现金−300万，口碑−2）/ 硬扛（口碑−8，风险+6，秦孃孃好感−15）。

**第三幕·罗劲的曲线（疯牛最后一月）**
罗劲拿着一张曲线来要额度：「再给一点，就一点。」这是本作最重要的抉择。选项：满仓（下月起股灾，自营亏 40%+）/ 维持 / 清仓（罗劲好感−12，他会在股灾后回来说"您是对的"，或者不回来——看他的主线）。

股灾期还有一条对应的三幕："强平那天"（两融）、"秦孃孃的电话"、"董事会问责"。

## 六、五个部门（都是人，不是词条）

### 6.1 经纪：营业部

复用银行版"网点"系统：有星级、月租、客户资产、派主任、装修。开局三家，可扩到六家。

| id | 营业部 | 星 | 租金 | 一句话 |
|---|---|---|---|---|
| jfb | 解放碑营业部 | 5 | 15 | 九三年的老店，大户室里坐着半部重庆股市史 |
| gyq | 观音桥营业部 | 4 | 10 | 商圈年轻白领，基金卖得动 |
| spb | 沙坪坝营业部 | 3 | 6 | 大学城，开户多、资产少、流失快 |
| jbz | 江北嘴营业部（可开） | 5 | 20 | 金融城旗舰店，面子工程，机构客户 |
| np | 南坪营业部（可开） | 3 | 7 | 老小区，退休金炒股的多 |
| wz | 万州营业部（可开） | 2 | 4 | 下沉市场，没竞争，也没量 |

装修档位换成"大户室"：普通→VIP 大户室→私人银行级。大户室影响秦孃孃这类客户的留存。

### 6.2 财富：代销

不单设部门，是营业部的一个动作和一堆事件。核心张力就一条：**基金好卖的时候都是牛市顶部，卖出去的都会在股灾后回来找你。**"冲基金代销"在情绪≥亢奋时冲的量，股灾后按比例生成投诉事件。

### 6.3 投行：项目卡

项目池 8–10 个，每季出现 1–2 个候选。每张卡：

```
{id, name, type: IPO|定增|公司债, months: 工期, fee: 总费, stages:[签约,尽调,申报,过会/发行],
 hidden: {fraud: 0~1 造假概率, delay: 拖延概率}, npc:"tang"?, flavor}
```

- **公司债**：3–4 个月，费 200–400 万，几乎不出事，周砚看不上。
- **定增**：5–7 个月，费 600–1200 万，中等风险。
- **IPO**：10–14 个月，费 3000–6000 万，是本作的头奖。每局至多两单 IPO 机会。造假概率 20–40%，尽调一次揭示一半，两次揭示全部。

尽调发现问题后的选择：终止（收已收费用，周砚好感−）/ 要求整改（工期+2）/ 装没看见继续报（费用照收，dirt+3，一年内 30% 概率暴雷 → 罚单+暂停保荐资格 12 个月+结局线）。

示例项目：`山城精工`（唐启川，IPO，应收账款有问题）、`两江云计算`（定增，靠谱）、`渝东水泥`（公司债，稳）、`巴渝生物`（IPO，造假率 70%，费 6000 万，周砚说"这单做完我就是保代里的名人"）。

### 6.4 自营：三档

不做资产配置器。只有 **空仓 / 半仓 / 满仓** 三档，自营池 10 亿。月收益 = 池 × 档位/2 × (大盘×1.2 + alpha)。罗劲的星级给 alpha（每星 +0.3%/月），倦怠高时 alpha 变负。

自营的所有戏在人身上：罗劲牛市要额度、股灾要"加仓摊薄"、修复期要"翻本"。玩家每次拒绝他，好感掉；每次答应他，钱在他手里。

### 6.5 研究所

P1 内容。花 1 精力 + 2000 万建，之后每月分仓佣金。贺予非的三幕主线全在这里：拉票新财富、研报上热搜、喊出一个离谱点位。研究所是本作最轻松也最出梗的一条线。

## 十二、文案规范（命根子）

- 白描、短句、重庆味。写「冉建国把烟掐了」，不写「冉建国很沮丧」。
- 数值反馈写进叙述结尾：`口碑+4` `客户资产−0.3亿`。
- 券商黑话可以用，不解释：万二五、大户室、分仓、保代、过会、穿仓、关灯吃面、旗手。玩家不懂会去查，查了就记住了。**游戏里不出现任何"什么是经纪业务"的解释性文字。**
- 禁：感叹号连用、翻译腔、说教、"我理解你的处境"、排比、结尾升华。
- 所有人物说话要能听出是谁：许伯衡话少、冉建国带方言、周砚用书面语、罗劲短句加数字、沈清禾复述你的原话、贺予非爱用标题、秦孃孃叫你"小伙子"。
- 股吧发言允许网络梗，但只允许股民真的会说的那种（关灯吃面、韭菜、旗手、A 股三千点），不允许通用网络烂梗。
