# 12 · 配色系统

## 为什么不是「整套染成红绿」

设计稿 §12 定了红线：**涨红跌绿**。如果把整个界面直接染成红或绿，会撞两次车——满屏绿的时候来一根红色涨幅，刺眼；深绿底上再放一个行情绿的跌幅数字，看不清。

所以做成两层，底色和语义色分开管。

## 两层结构

**第一层：皮肤（底色）。** 一整套 CSS 变量，包括底色、面板、卡片、分隔线、遮罩，以及 `--up` / `--down` 这两个语义色。红底和绿底这两套里，`--up` / `--down` 会被提亮（红底下的跌是 `#3fc796`，绿底下的涨是 `#ff6b4a`），保证数字在同色底上还看得清。**不管哪套皮肤，涨永远是红、跌永远是绿，加上「涨/跌」两个字，这条不动。**

**第二层：气氛。** 跟着行情阶段走，只在藏青底上生效。做法是把藏青那一套变量往红盘/绿盘那一套上混，比例按阶段给：

| 阶段 | 混向 | 比例 |
|---|---|---|
| 冷清 | — | 0（只压暗一点） |
| 回暖 | 红盘 | 0.32 |
| 疯牛 | 红盘 | 0.72 |
| 股灾 | 绿盘 | 0.68 |
| 修复 | 绿盘 | 0.30 |

混向的目标本身就是深色，所以不会像「藏青混纯红」那样中途变成灰紫。另外顶部叠一层 radial 光晕（`body::before`），疯牛和股灾时给顶栏加一圈辉光。切换有 1 秒过渡。

## 玩家可选的六套

工具条上的 🎨 配色，存在 `yjzq_meta.skin`，跨局保留。

| id | 名字 | 行为 |
|---|---|---|
| `auto` | 随行情（默认） | 藏青打底，按上表随阶段偏红偏绿 |
| `mkt` | 红绿盘 | 底色直接翻：疯牛/回暖用红盘，股灾用绿盘，冷清/修复回藏青 |
| `navy` | 藏青 | 固定，不随行情变 |
| `red` | 红盘 | 固定暖红 |
| `green` | 绿盘 | 固定深绿 |
| `ink` | 夜盘 | 近黑中性 |

## 实现位置

- `p1.html` — `:root` 全套变量；`html[data-skin=...]` 四套底色；`html[data-skin="navy"][data-amb=...]` 五个阶段的气氛调色；`body::before` 光晕。原来写死的十几个十六进制底色全部换成变量，新增皮肤不用再改结构样式。
- `p3.js` — `SKINS` 表、`applyTheme()`、`setSkin()`、`showSkin()`、`cssv()`。`META.skin` 默认 `"auto"`。
- `p7.js` — `renderHeader()` 里设完 `--cycle-image` 紧接着调 `applyTheme()`；顶栏折线图改用 `cssv("--up")` / `cssv("--down")` / `cssv("--gold")`，跟着皮肤走。
- `p8.js` — 启动时 `loadMeta()` 后调一次 `applyTheme()`，并导出 `window.showSkin` / `window.setSkin`。
- 结局长图（`makeBio` 的 canvas）**不跟皮肤变**，固定藏青。那是要发出去的图，要的是牌子统一。
