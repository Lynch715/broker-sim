## 3. 分阶段施工单

### S0：把“能玩”写成确定接口

- [ ] 将万元作为唯一内部金额单位；所有UI转换集中到formatMoney。
- [ ] 补齐四路线具体修正、季度目标、客户流入区间修正、董事会扣分规则；所有数值入BALANCE。
- [ ] 明确状态：setup / planning / event / settling / report / ended；每个状态合法动作清单。
- [ ] 事件schema包含id、触发条件、互斥条件、一次性、冷却、截止月、选项、确定成本、随机效果、责任记录。
- [ ] 明确投行里程碑与已确认费用字段，写撤回、回款、完成的唯一处理路径。
- [ ] 固定seed与rngState入档；UI渲染不抽随机数。
- [ ] 资源manifest列39项，标注占位/待生成/待验收/通过，不能只写总数。

### S1：先让账和月份可信

- [ ] 四个基础行动、精力扣减、成本预览与禁用原因。
- [ ] 月结顺序：锁输入→已选行动与到期任务→市场变化→客户资产/公司持仓估值→手续费/项目收入与成本→指标/责任更新→失败检查→月报快照→保存。
- [ ] 月结使用monthId一次性凭证；快速双击不能扣两次工资或进入两个月。
- [ ] 固定开局空操作算例：−13.6万元；维护客户示例：−18.52万元。
- [ ] 顶部风险告警、账目详情、剩余精力确认与一个事件对话框。
- [ ] 12月从开局至测试终局能完整点击；P0测试结束不是三年正式结局。

### S2：一条完整项目链胜过十个假入口

- [ ] 经纪与财富互斥资产池，转池守恒，保住客户不额外当新增。
- [ ] 费率促销为带起止月的修正记录；多次促销不得无期限叠乘。
- [ ] 投行五阶段，成功/补正/撤回，3笔费用不重复；工期与月事件队列联动。
- [ ] 自营买入/市值/卖出逐笔核对；成交成本计入当期损益。
- [ ] 资本占用、现金缓冲与强制应急出售入口。
- [ ] 存档key：broker_sim_save_v1；局外key：broker_sim_meta_v1。禁止读写jbzh_*。
- [ ] localStorage异常、损坏JSON、旧版本迁移、重开不删图鉴；导入存档做结构与数值校验。

### S5：验收和打包

- [ ] 确定性账务测试：正常、转池、促销到期、投行撤回、自营卖出、现金缺口。
- [ ] 至少3种策略×100相同种子批测，报告通关率、亏损率、现金最低点、平均点击量；不只报“跑了300局”。
- [ ] 稳健策略通关目标60%—85%，盲目扩张在回撤期显著更差；这是校准目标，当前未经测试。

- [ ] 同源HTTP载入，无404或未捕获错误；断网测试依赖已内嵌资源。
- [ ] 发布包从全新目录独立启动；银行文件与存档不变；无真实公司推广链接、旧二维码或标题串入。

## 4. 风险与调整规则

| 风险 | 触发信号 | 对策 |
|---|---|---|
| 系统过多，新手看不懂 | 前3月解释超过两屏，玩家不知下步 | 延迟入口，保留一句话解释和动作建议 |
| 券商业务做成纯炒股 | 自营贡献绝大部分分数 | 限敞口，多维结局，调整服务/项目回报 |
| 资本充裕导致缺乏压力 | 36月全放弃也稳定高分 | 以董事会、流失与团队状态校准；不伪造现实资本规则 |
| 图好看但不能用 | 手机切人、中文画在图上 | 分版构图、文字由代码排、运行时检查 |
| 项目周期不确定 | 事件拥堵、退出条件失效 | 明确截止与退出，测试最坏路径 |
| 文案/美术拖期 | D17仍缺关键主线 | 降低非关键插画优先级，保留全部因果节点 |
