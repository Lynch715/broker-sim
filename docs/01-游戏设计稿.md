# 《模拟券商：总经理的三年》游戏设计稿

版本：v0.1 提案｜日期：2026-09-13｜状态：设计交付，尚未完成正式游戏开发

## 1. 先用一句话说清楚

你接手一家扎根山城的小型证券公司，用三年时间决定它靠什么挣钱：服务客户、争取企业融资项目，还是拿自己的钱投资；行情会变，人会离开，今天挣到的钱可能补不上明天的窟窿。

**建议定位：有职场故事的回合制经营游戏。** 玩家是公司总经理，兼顾经营、用人和风控。延续银行版的36个月、每月3点精力、月报、人物关系与多结局。一局目标时长45—75分钟；这是待试玩验证的设计目标。

暂定游戏名《模拟券商：总经理的三年》；公司暂名“江州证券”，城市“江州”取山城地形与生活气质。均为虚构设定，发布前再查重。开局身份是总部总经理，不能写成可以随意开展自营、承销的营业部负责人。设定公司已经具备游戏涉及业务的相应资格；后续“解锁”代表内部团队与制度准备，不等于取得现实业务许可。

## 2. 不懂券商，也能看懂这五件事

| 业务 | 白话解释 | 游戏里你做什么 | 钱从哪里来 | 难处 |
|---|---|---|---|---|
| 经纪 | 帮客户完成证券交易 | 获客、服务、定佣金、升级系统 | 客户成交额带来的净手续费 | 佣金战、行情冷清、系统稳定性 |
| 财富服务 | 帮客户理解产品、做匹配与持续服务 | 判断需求、配置服务团队、售后回访 | 简化后的销售及持续服务收入 | 错配、赎回、客户信任流失 |
| 投资银行 | 帮企业进行融资等资本市场事务 | 选项目、派团队、尽调、准备材料、等待结果 | 按合同与阶段收取的项目费用 | 周期长、会撤回、回款有条件 |
| 自营投资 | 公司用自己的钱投资 | 在现金、债券篮子、股票篮子之间配置 | 利息及投资损益 | 亏损由公司承担，占用资本与流动性 |
| 融资融券 | 按条件向客户提供融资或融券服务 | 后续版本增加额度与担保品管理 | 利息或相关费用 | 信用、担保品和流动性风险 |

首发落地前四类。财富服务首发仅表现产品销售与持续服务，不直接等同于证券资产管理；自主管理产品、两融、衍生品、做市与境外业务均放入后续候选，不占首发施工量。

业务分类参考中国证券业协会投资者教育资料；现实风控同时涉及净资本与流动性等要求。游戏采用单独命名的简化参数，不把游戏阈值宣传为监管规定。来源及使用边界见文末。

## 3. 如何继承银行版

参考材料：银行项目当前 `index.html`、`docs/01-设计建议.md`、`docs/02-施工规范.md`，并通过本地HTTP查看了其实际首页。现版代码可见36月、3点精力、四路线、六人物、网点/团队/关系/贷款/排行/日志、种子与传记等机制。此处是定向参考，不代表对银行版完成了完整回归。

| 银行版骨架 | 券商版对应 | 处理 |
|---|---|---|
| 三年任期、每月3点精力 | 三年经营合同、每月3项重点工作 | 继承节奏，普通查看不耗精力 |
| 存款驱动经营 | 客户资产 × 交易活跃度/服务费率 | 重建收入模型，不能换名照搬 |
| 贷款客户与不良 | 投行项目与延迟责任 | 重建里程碑，项目款不是贷款利息 |
| 网点与员工 | 业务团队、营业部与系统 | 营业部扩张放P2，P0先用总部团队 |
| 人情与关系线 | 董事长、团队、企业客户与竞争对手 | 保留对白和选择代价 |
| 宏观周期 | 冷清—回暖—过热—回撤—修复 | 给预兆，不提前告诉准确收益 |
| 季考与排名 | 董事会季度问询、同规模券商对比 | 采用利润、客户、信任、风险综合分 |
| 把柄 | 有来源、有到期日的责任记录 | 不能靠一次团建或普通风控行动清空 |
| 传记与图鉴 | 总经理任期报告、公司结局与人物后记 | 保留传播与重玩动机 |

不直接拷贝银行角色姓名、剧情、存档键、推广二维码或资源路径。新项目与银行项目完全独立。

## 4. 开局与核心体验

上任时：自有现金30,000万元；自营持仓0；净资产30,000万元；交易服务资产80亿元；财富服务资产20亿元；客户信任60；团队士气65；合规风险15；董事会耐心60；当月精力3。

客户资产按服务归属划分为互斥两池，总额100亿元；同一个客户可以现实中使用多项服务，但首发按其资产主服务归属计量，避免重复加总。产品申购可从交易池转入财富池，必须一减一增。行情导致的估值变化和真正资金流入，在月报分列。

开局有三个部门负责人，其他工作人员汇总为基础运营成本；不能让三个角色看起来承担整家公司的全部法定岗位。首发最多6个关键人物/岗位卡，不模拟真实人员编制。

开场对白：

> 董事长把去年的报表推过来。\n“牌子还在，客户也在。就是没挣到什么钱。”\n窗外的江上起了雾。手机响了，是财富部负责人。\n“有个老客户要转走两千万。您先见人，还是先开会？”

### 前三个月：把教程藏进工作

1. 第1月只突出经纪与团队：查看“客户资产不是公司现金”的提示；处理转户客户；安排服务与休整；第一次月报解释收入和成本。提示可跳过，不强制最优路线。
2. 第2月开放财富服务：同样销售额，匹配不同客户需求会带来不同留存结果；看到“今天卖出去，后面还要服务”。
3. 第3月第一次董事会问询；展示投行机会和自营设置入口，第4月才允许投入。前三个月免突发强制终局，但支出、风险和责任正常记录；第4月恢复完整检查。

### 一个月的闭环

晨会简报 → 看本月风险与两条机会 → 花3点精力 → 处理即时选择 → 确认月结 → 月报解释变化 → 最多2个主要剧情卡 → 自动存档进入下月。

读报、查账、查看人物与词条免费；配置变化、签项目、做营销等必须走行动确认。每个行动先显示确定成本、预期区间、影响期限和不确定来源。剩余精力允许主动放弃；确认框说明不结转。

首页展示六张卡：自有现金、客户资产、本年累计经营损益、客户信任、合规风险、团队士气。另有“本月精力”和董事会目标。净资产、自营持仓、资本空间、现金缓冲在经营详情展开。

## 6. 可施工的经济模型（数值为初始种子，尚未完成平衡）

所有金额内部统一万元；80亿元=800,000万元。以下费率、收益区间、门槛均为游戏参数。

### 6.1 经纪与财富

- 经纪收入 = 当月平均交易服务资产 × 月换手倍数 × 净佣金率。
- 第1月教学固定月换手0.60，第2月起使用市况表的换手基准；净佣金率0.00018；80亿客户资产对应86.4万元月收入。净佣金已简化扣除通道性费用，避免再扣一遍。
- 财富收入 = 当月平均财富服务资产 × 年化综合服务费率 / 12。
- 初始20亿元、年化综合服务费0.0048，对应80万元/月。此为游戏混合口径，不代表每种现实代销业务都可按保有量收费。首发不额外叠加申购费或业绩报酬。
- 平均资产=(月初资产+月末资产)/2；已结算月份不得重新应用月底新参数。资产变动顺序：明确净流入/转出 → 对存续资产计市场估值 → 计算期末资产 → 求均值。
- 客户资产估值：交易池使用市场股票篮子涨跌×0.45；财富池使用债券篮子涨跌×0.70+股票篮子涨跌×0.10，其余视为现金。系数仅是首发组合代理；调参集中管理。
- 净流入、赎回不直接增加公司现金或损益。信任影响留存和新客转化，开户数量不是唯一目标。

### 6.2 成本与开局算例

基础月成本180万元=人员120+系统与场地30+其他运营30。关键人员薪酬包含在120内；新增招聘才增加基准之外的薪酬。开局无投行、自营和事件时：收入166.4，成本180，经营损益−13.6；现金29,986.4，净资产29,986.4。资本较充足，正常失败压力主要来自董事会和经营恶化，而不是几个月工资就耗尽一家证券公司资本。

“维护重点客户”示例成本6万元，当月交易池净流入2亿元且无行情变动：平均交易池81亿元，经纪收入87.48；财富80；固定180；行动成本6；本月损益−18.52，期末现金29,981.48。动作有客户长期价值，不应因短期收益低而自动判坏。

### 6.3 投行：钱要按阶段挣

每个项目有：企业背景、融资类别、预计工期、团队要求、总服务费、各阶段成本、完整度、疑点、市场窗口、回款状态。首发采用“合同签订—尽调—申报准备—外部流程等待—完成/撤回”五阶段，外部流程是抽象节点，不模拟具体审批权。

示例“山城精工融资项目”：预计6—9个月；总费用上限300万元；尽调60万元、后续工作30万元；在完成相应服务且满足合同条件时收取30/30/240万元。后三笔分别是各阶段费用，不额外再记一次300万元。撤回只保留已经按条件确认的费用，未赚取的预收款首发不建模，避免把订金当利润。每月自动推进条件与经理花精力的关键节点分开。

项目完成度≠成功率；尽调降低未发现问题概率，不能保证融资成功。至少1条“主动终止问题项目，短期亏钱但保住长期合作”的正向剧情。

### 6.4 自营：先分清利润与现金

第4月开放，仅有现金、债券篮子、股票篮子。配置股债总持仓不超过上月净资产的35%，另受资本空间限制；上限可配置。禁止单只真实股票、实时行情、短线点价与无限杠杆。

买入：现金减少、持仓增加，**不是费用**。市值涨跌：改变持仓和当期损益，不直接改变现金。卖出：现金增加出售所得、持仓减少；已在历月确认的估值损益不重复计入本月。首发篮子收益按含收益的总回报建模，不再另加一次债券票息。

对账例（暂忽略交易成本，以单独验证本金与估值不重复记账）：30,000万现金买入1,000万股票篮子→现金29,000、持仓1,000、净资产30,000；上涨10%→持仓1,100、累计损益100、现金仍29,000；全部卖出→现金30,100、持仓0，本次卖出不再凭空增加100利润。

股票月回报常态区间约−8%至+8%，剧情压力区间−22%至+18%；债券常态−1%至+1%。均为测试分布，不构成现实预测。超出常态的压力事件提前出现线索，但结果仍有不确定性。自营盈利不能增加客户资产。

### 6.5 风险与流动性

资本占用点=股票自营市值/初始净资产×200 + 债券自营市值/初始净资产×40 + 活跃投行项目数×8 + 未整改重大责任数×15。上限100点，≥80提醒；提交新行动后预计超过100即拦截。不是净资本或风险覆盖率公式。

现金缓冲=自有现金−未来6个月固定成本−已签约未支付项目预算。缓冲为负提示压缩计划；支付型行动需同时满足即时现金和资本限制。自动到期支出仍可能造成缺口；现金<0进入一个月应急处置，次月月底仍<0则资金链失败。自营资产可出售，但不得调用客户资产补缺口。

合规风险≥70增加检查与整改压力；风险100触发严重事件审核。未解决严重责任与风险值分开，责任不能靠下降数值抹掉。检查结果依据已登记事件、证据与整改，不纯掷骰“凭空判罪”；人物好感不能取消正式责任。

## 8. 市场不是背景图

36月有五种市况：冷清、回暖、过热、回撤、修复。基准阶段长度6/8/6/8/8月；相邻边界各抖动±2月且阶段不少于4月。首发每局至少有一次回撤，结果按种子可复现，阶段不是对现实未来的预测。

| 市况 | 换手倍数基准 | 主要机会 | 主要危险 |
|---|---:|---|---|
| 冷清 | 0.35 | 低成本获客、培养团队 | 佣金不足以覆盖扩张成本 |
| 回暖 | 0.65 | 活跃度与融资意愿提高 | 招人和系统容量跟不上 |
| 过热 | 1.10 | 经纪旺、项目多 | 客户错配、追涨、团队过劳 |
| 回撤 | 0.40 | 守住信任、处理问题项目 | 估值回落、转户赎回、自营亏损 |
| 修复 | 0.55 | 服务口碑兑现、再投人力 | 前期责任追溯，急着翻本 |

普通切换前1—2月发出新闻信号；重大危机分“线索—决策—后果”三幕。每月最多1个主要随机事件+1个主线事件，其余进入有截止日的队列；关键财务与任期警报不得延迟。预兆不是告诉玩家下个月准确涨跌。

## 10. 可直接改成事件的样本

### E01 老客户要转户（第1月教程，林知夏）
“他说隔壁佣金便宜一半。”林知夏把手机扣在桌上，“在咱们这儿八年了。”

- 见面复盘服务：支出6万、1精力，保住既有0.2亿资产，信任+3；不能再把保住的存量加作新流入。
- 给予三月费率优惠：不额外耗精力，受影响客户费率降20%，保留客户；对应部分收入减少，不全公司佣金减半。
- 接受转出：交易池−0.2亿、信任−1；无现金费用。

### E02 一张风险测评（第5月起）
客户只说了两遍：“这笔钱年底有用。”销售把产品说明书往前挪了挪。

- 换成期限匹配的方案：本次净流入减少0.1亿，信任+4，无责任记录。
- 先暂停销售，补做沟通：占用1精力、3万服务成本；下一月再决策。
- 忽略不匹配继续销售：当月可能完成指标，风险+12，登记“适当性争议”；后续投诉、退费与人员责任按线索处理，不显示规避监管教程。

### E03 财务报表里的那笔应收款（投行第2阶段）
周砚在那一行下面画了三次。“客户说，年底肯定回来。去年也是这句话。”

- 补充核查：1精力、20万，工期+1月，揭示风险标签。
- 要求企业整改：工期+2月，合作度−4，满足条件后恢复推进。
- 终止项目：支付已发生费用，不确认未挣取收入；短期亏损，风控与长期口碑正向。

### E04 大涨之后的额度申请（过热阶段）
罗劲带来一张曲线。“再给一点额度，就一点。”

- 维持配置：无费用，不改变敞口；合作度−3。
- 按既定上限调仓：1精力、交易成本，显示调整后的现金和资本占用。
- 减仓锁定现金：1精力；不保证卖在最高点，随后涨跌照常发生。

### E05 上午九点二十七分（高活跃月）
客服那边一下站起来三个人。屏幕还能刷新，单子发不出去。

- 启用应急系统：现金−40万，暂停新增营销一个月，客户流失降低。
- 延后营销先修系统：1精力、25万，收入少一部分，信任−2。
- 忽略故障继续拉新：风险+10，流失扩大，形成服务争议。

### E06 降薪表上的签字（连续亏损季度）
林知夏把签字笔放下。“他们上个月周末都在回访，您知道。”

- 保持团队：维持月成本，士气+5，董事会耐心−3。
- 自愿协商调整激励：下季浮动支出−10%，士气−4；不改固定薪酬。
- 缩减新项目与招聘：不开新坑，团队倦怠−8；新业务增长放缓。

首发内容量：36条普通事件（四业务各6、团队6、合规6）+6人物×3幕=18幕+3危机×3幕=9幕+6条董事会节点，共69个内容节点；教程复用E01等既有条目，不重复计算。四同业共12条短讯独立计数。

## 11. 路线、评分与结局

首次开局推荐“客户立业”；其他路线可选且有解释。四路线：客户立业（获客/留存）、项目突围（投行）、投研驱动（自营与研究）、稳健经营（风险控制）。共用所有核心业务，路线是倾向，不永久封死其他玩法。首发各路线加成与目标在BALANCE配置；P0不先做四套独立教程。

36月任满分数=盈利30+客户25+信任20+风险管理15+团队10，各项先归一化为0—100再加权。盈利目标累计3,000万、客户增长目标50%、平均信任目标80、团队目标75为初始调参目标；风险分由峰值风险与未整改责任扣减。达到分项目标得该项满分，超额不继续膨胀；客户增长以净流入为准，排除市场浮盈。

董事会每季按上季经营损益与路线季度目标解释耐心变化，单季下调上限15；耐心≤0且连续两季未达标→被更换。任满评分不直接覆盖失败原因。终局优先级：资金链失败→重大责任导致离任→董事会更换→任满路线成就→普通任满。重大责任结局必须有已发生的严重事件链证据，不能因关系人好感低凭空触发。

首发8个主结局：客户长留、项目立身、投研成名、稳健掌舵、平稳交班、董事会换帅、资金链断裂、责任离任。前四分别对应路线目标且总分≥75；未达成则平稳交班。角色后记作为附加维度，不把组合都计为独立主结局。12项成就、8结局图鉴、任期报告长图，局外仅解锁新的开局偏好，不直接无上限加钱。

任期报告：身份与路线、期初/期末资产与净流入、累计损益、最难的三次选择、6—8个关键节点、人物后记、种子与版本。首发不放二维码，发布地址确定后再独立制作与验码。
