## 二、BALANCE 变更（相对 05 给的骨架）

只有这几处动了，都是为了让 4.3 的「开局月亏 180 万」和 11.1 的评分目标对得上：

1. **新增 `cost.branchPerStar: 10`**（营业部运营：人力／双录／水电，按星级计）。
   05 骨架里只有 `hq` 和租金，但 6.1 的租金表（15/10/6）加起来只有 31 万，和 4.3 算例里的「营业部 120 万」差一个量级。保留 6.1 的租金表不动（那是给玩家看的），把差额放进一条独立成本行，好处是开营业部的压力会随星级正确上升。
   开局实算：350（总部）+ 31（租金）+ 120（运营）+ 43.2（薪酬）+ 30（系统）= 574 万；收入 375 + 83 = 458 万；**月亏约 116 万**，比 4.3 的 180 万略轻，因为薪酬只有三个人。
2. **`emp.salaryPer: 0.9 → 1.6`**（月薪＝三维之和 × 该系数）。
3. **`aum.baseInflow` 全面下调**：`{cold:-0.007, warm:0.006, mania:0.020, crash:-0.032, recover:0.002}`；`outlet.perStar 1250 → 640`；`mood.inflowMul` 疯狂档 2.6 → 2.1；`aum.trustPer 0.0003 → 0.00022`。
   原因：按骨架数值跑，随机策略三年净流入能到 +59%，11.1 的 +40% 目标形同虚设。调完随机策略中位 +23%，好好打才够得着 40%。
4. **新增 `margin` 段**：`{rate:0.08, cost:0.04, penetration:{0:0,1:0.005,2:0.02,3:0.05,4:0.08}, adjust:0.35}`。
   **这一条需要设计过目。** 05 把两融整体放在 P1，但 P0 要求股灾三部曲成立，而「强平那天」没有两融余额就没得演。处理办法：P0 里两融余额按情绪档自然渗透（散户自己加杠杆，玩家不做决策），只产生利息收入和强平戏；P1 再把「解锁 / 额度 / 担保品」这些玩家决策层加上去。自营面板里写了「玩家可操作的两融业务在 P1 开放」。
5. **`xu.quarterPenalty: 6 → 12`**，并新增三条季度扣分（利润落后进度、现金低于 2 亿、吃了罚单、风险≥60）。不加这些，随机策略下「董事会换帅」只有 3%，远低于 4 节的 20% 目标。
6. **排名映射**：`rank = 140 − 0.1201 × (实力分/市况系数 + 124.2)`，开局正好落在 96。市况系数 = `(点位/2900)^0.7`，用来实现 4.5 说的「牛市里所有券商都涨，排名靠相对」。

## 三、自测结果

### simBatch(400)，随机策略

```
中位客户资产 476.5亿   中位现金 12.9亿   中位累计利润 5.2亿
中位净流入 70.2亿（+23%）   中位排名 53   中位总分 68
存活率 81.3%   破产率 0%（"破产"一栏统计的是所有失败结局）

结局分布：平稳交班 245 (61.3%) · 董事会换帅 75 (18.8%) · 经纪之王 73 (18.3%)
          牛市幸存者 5 (1.3%) · 干净的第一名 2 (0.5%) · 风险处置 0
评级分布：B 124 · C 102 · BB 98 · BBB 48 · A 22 · AA 6
```

对照 05 第 4 节的校准目标：

| 目标 | 实际 | 判断 |
|---|---|---|
| 平稳交班 45% | 61.3% | 偏高 |
| 路线结局 20% | 18.3% | 达标 |
| 换帅 20% | 18.8% | 达标 |
| 风险处置 <10% | 0% | 达标，但基本没触发 |
| 隐藏 <5% | 1.8% | 达标 |

平稳交班偏高、风险处置为零，是同一个原因：随机策略手里现金太多（开局 8 亿，三年亏不完），触发不了「连续两月现金为负」。真人玩家会去开营业部、升系统、赔付客户，现金压力比机器人大得多。**如果设计觉得必须把风险处置压到 3–8%，最直接的杠杆是把开局现金从 8 亿降到 4–5 亿**，等设计定夺，我不擅自动。

### 对账红线（05 第 2 节），全部通过

- **客户的钱不流入公司现金**：逐月核对「现金变动 == 经纪 + 代销 + 两融息 + 投行 + 自营 − 成本」，36 个月零偏差。`aum` / `fundHold` / `margin` 没有任何一条路径直接写进 `cash`。
- **估值与净流入分账**：逐月核对「客户资产变动 == 估值变动 + 本月净流入」，零偏差。传记和评分只用累计净流入，浮盈不计。
- **佣金档当月生效，不重算历史**：`feeRate()` 在结算当刻取值。
- **存档任一月读回续玩到 36 月零报错**：随机停在 1–35 月存档、读回、跑完，40 次零报错。
- 自营买入不计费用，估值涨跌直接进当月损益与现金。

### 三部曲触发率（120 局）

开户潮 98 · 九点二十七分 90 · 罗劲的曲线 87 · 强平那天 86 · 秦孃孃的电话 84 · 董事会 80。
没到 120 的部分全是**该局在疯牛／股灾之前就结束了**（换帅或风险处置）。健在的局里六幕必发——每幕给了「最早月份」，同月撞车就顺延到下月补，不会漏。
例外：「九点二十七分」系统升到 3 级就不发，这是设计稿写的。

### 手工冒烟（390px，Chromium）

新开局连点 4 个月（跑业务×3 → 结算 → 月报 → 事件），无控制台报错，横向零溢出。六个 Tab 全点过。刷新读档回到原月份。四个弹窗窄屏都过了：开户潮、月报（含股吧、"↓ 下面还有"滚动提示）、分类评级证书、传记长图。可点元素均 ≥44px。

## 四、需要设计拍板的几处

我按规范「拿不准的回问设计」的要求，先按合理默认做了，但这几处请过目：

1. **P0 的两融口径**（见 BALANCE 变更第 4 条）。
2. **路线结局怎么判**。P0 没有路线选择动作（设计稿没有银行版那样的开局选流派），我按三年实际经营反推：
   - 经纪之王 = 客户净流入 ≥ +45% 且总分 ≥75
   - 稳健老店 = 案底 0 且风险 <40 且口碑均值 ≥68 且总分 ≥75
   - 投行名门 / 投研之光的位子在结局表里留着，P1 有了投行和研究所才够得着。
   如果设计想让路线像银行版一样**开局选**，那是一次结构改动，P1 一起做更合适。
3. **开局现金 8 亿是不是太厚**（见上，影响风险处置的触发率）。
4. **E06「尽调路上」和唐启川**整条线随投行项目卡进 P1，文案已经在设计稿里，我没提前写。
5. 秦孃孃那句「明年一定回本」的承诺（股灾三部曲第二幕），我埋了 `flags.qinPromise`，但**兑现／打脸的判定还没写**——它更适合放在 P1 的秦孃孃主线第三幕里收。这是 P0 唯一一个挂在半空的钩子。
6. **文案请设计通读一遍再进 P1**（05 里也是这么写的）。我按第九节那十条的尺子写了 23 条普通事件、6 幕脚本、59 条股吧、16 条同业群、七人后记、11 条结局文案。自评：营业部和股灾那几条味道到了；「茶水间那台电脑」「营业部的租约」两条偏平，如果设计要改，这两条优先。
