# 14 · 应用图标与添加到主屏幕

## 原来为什么不好看

两件事。

一是图标本身。最初那张 `icon-app` 是深蓝底上一条细金线（山形 / K 线），概念对，但线太细，缩到主屏幕上的六十几个像素基本糊成一团。

二是格式。它是 WebP。**iOS 的 apple-touch-icon 只认 PNG**，给 WebP 等于没给——Safari 会退回去截一张页面的图当图标，所以添加到桌面看起来像张网页缩略图。

## 新图标

深蓝底（跟游戏底色同一套），中间一个大号衬线体的 **渝**，金色，上亮下沉带一点外发光；底部一条通栏细条，左红右绿——就是游戏里「涨红跌绿」那条红线。

几个取舍：

- **字选「渝」不选「券」或抽象图形**。渝江证券是重庆的，渝是重庆的简称，全主屏幕不会有第二个 app 是这个字。抽象 K 线图谁都在用，认不出是哪个。
- **衬线体**（Noto Serif CJK Bold）。券商招牌的感觉，黑体太像互联网产品。
- **满版不切圆角**。iOS 自己会套圆角遮罩，图标里再切一次会出现双层圆角。
- **底部那条通栏红绿条**顶到边，圆角遮罩只会切掉两个角，看起来是故意的。
- 另出了一版 **maskable**（内容缩到 74%），给 Android 自适应图标做圆形裁切用。

## 文件

跟 index.html 放同一层：

| 文件 | 用途 |
|---|---|
| `apple-touch-icon.png` (180) | iOS 添加到主屏幕 |
| `icon-192.png` / `icon-512.png` | Android / manifest |
| `icon-maskable-512.png` | Android 自适应图标 |
| `icon-32.png` | 浏览器标签页 |
| `manifest.webmanifest` | 全屏启动、名字、主题色 |

`manifest` 里 `display:standalone`，加到主屏幕后不带 Safari 的地址栏和工具条。

## 单文件怎么办

这游戏的卖点之一是单文件，所以图标做了两条路：

- `<head>` 里写的是指向同目录那几个 png 的相对路径（托管时走这条）；
- 启动时探测 `icon-192.png`，加载失败说明这份 HTML 是被单独拎出来用的，就把 head 里那几个 link 全删掉，换成内嵌的 192 PNG（base64，+10KB），同时用 Blob 现做一个 manifest 顶上，全屏启动照样有。

内嵌那份也从 WebP 换成了 PNG，因为 apple-touch-icon 不吃 WebP。

## 顶部安全区

`#app`、弹窗、结局屏、开场屏的上内边距都加 `env(safe-area-inset-top)`。这个只在全屏启动（状态栏透明）时不为零，普通浏览器里是 0，不会多出空白。不加的话，加到主屏幕后顶栏会钻到刘海底下。
