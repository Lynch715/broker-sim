# 13 · 手机端适配

## 禁缩放

`user-scalable=no` 从 iOS 10 起就被 Safari 忽略了，光靠 meta 挡不住，所以三道一起上：

1. **meta** — `width=device-width, initial-scale=1, minimum-scale=1, maximum-scale=1, user-scalable=no, viewport-fit=cover`。启动时 JS 还会把页面里所有 `meta[name=viewport]` 重写成这一份，防止这份 HTML 被别的页面包一层壳、外层 head 里塞了个不带 `user-scalable=no` 的 viewport。
2. **CSS `touch-action`** — 全局 `*{touch-action:pan-x pan-y}`。只留平移，双指缩放和双击放大都没了。按钮原来写的是 `manipulation`，那个是允许双指缩放的，已经改掉。
3. **JS 兜底** — `gesturestart/gesturechange/gestureend` 一律 `preventDefault()`（Safari 专有的捏合事件）；`touchmove` 里两根以上手指直接吃掉，单指滚动不受影响；`dblclick` 挡一道。

**没有**在 `touchend` 里按 300ms 间隔挡双击——那种写法会把连点按钮的第二下一起吃掉，这游戏一个月要连点好几次行动卡，不能这么干。

## 布局

四个宽度实测（320 / 360 / 390 / 430），横向溢出 0 处。

- **安全区**：`#app`、`.mask`、`#endScreen`、`#guide .inner` 的四边内边距都加了 `env(safe-area-inset-*)`，配合 `viewport-fit=cover`，刘海和底部横条都不压内容。
- **热区**：`@media (hover:none)` 下统一加大——工具条 38px、Tab 44px、卡片按钮 40px、弹窗选项 48px、行动卡 74px。
- **320px 专项**：工具条四个按钮原来会把「重开一局」拆成两行，现在 `white-space:nowrap` + 缩一档字号内边距，一行放得下。
- **横屏**：`max-height:500px and (orientation:landscape)` 下顶栏压矮、折线图 60→44px、行动卡 66→58px。
- **弹窗高度**：`max-height:88dvh`（带 `vh` 回退）。iOS 的 `vh` 把地址栏算进去，用 `dvh` 才不会被截。小屏再放宽到 92dvh。
- **数字不拆行**：`.card .num b` 和 `.forecast b` 加 `white-space:nowrap`，原来 320px 下会出现「3447」换行、「万」单独一行。
- **滚动**：弹窗、结局屏、开场屏都加了 `-webkit-overflow-scrolling:touch` 和 `overscroll-behavior:contain`。
- **输入框**：种子输入框字号 15px→16px。iOS 遇到小于 16px 的输入框会自动放大整页。

## 顺手修掉的一个老问题

`.modal .body` 一直是 `white-space:pre-wrap`（事件正文靠空行分段，需要它）。但月报、评级、图鉴这三个走的是 HTML 模式，模板字符串里的缩进和换行也被 pre-wrap 当成了空白——图鉴里每张卡片之间撑出一大片空。现在 `showModal` 在 HTML 模式下给 `#mBody` 加 `htmlbody` 类，`white-space:normal`。

顺带把弹窗底部「↓ 下面还有」的渐变从写死的藏青改成 `var(--card)`，换皮肤时不会再露出一截颜色不对的底。
