# 21 · 载入与离线缓存

## 问题

安卓玩家反馈：页面只出现顶栏和几个标题，「公司账面」「本月安排」「经营账册」都是空的，点「结束本月」没反应。

截图里看到的 `2900.00`、`—`、`冷清`、`冰点`、`还剩120个月` 都是 HTML 里写死的占位文字，说明主脚本根本还没运行（运行过 `—` 会变成「开盘」）。也不是报错——所有报错路径都会弹「页面还没载入完整」面板。

真正原因：`index.html` 2.8MB，其中2.2MB是 base64 内嵌图片，全部在页面末尾的主 `<script>` 里。界面骨架在前58KB，浏览器很快画出来；主脚本要整块下完才执行。玩家截图里网速57KB/s，要等将近一分钟，期间页面看起来像坏了。GitHub Pages 在国内本来就慢。

本地以57KB/s限速复现，10秒时的画面与玩家截图一致。

## 改动

1. **载入遮罩**（`index.html` 开头）。`<html>` 还没有 `data-boot` 属性时盖一层「正在载入游戏……」，主脚本跑完（`ready`）或报错（`error`）自动消失。6秒后提示网络慢；25秒后出现「重新载入」按钮。页面加载结束但主脚本没跑起来，直接转到原有的启动异常面板。这段脚本只用 ES5。
2. **美术拆出**。`ART` 里33张 webp 和 `EMPLOYEE_PORTRAITS` 40张头像改为 `assets/art/*.webp`、`assets/employees/*.webp`，文件名带内容摘要（如 `cycle-cold.417a9710.webp`）。`icon-app` 那张3.6KB的 png 仍内嵌，用作旁边没有图标文件时的回落。存档里不存图片，旧档不受影响。拆分前的文件留在 `index.拆图前备份.html`。
3. **离线缓存** `sw.js`。首次打开后在后台缓存页面、图标和全部美术（约1.8MB）。之后：页面先用本机缓存秒开，同时后台取新版，下次打开生效；美术永久缓存；断网也能玩。只在 http/https 下注册，直接双击打开本地文件不受影响。

## 数字（浏览器实测，手机视口）

| | 改前 | 改后 |
|---|---|---|
| 页面大小 | 2.84MB（压缩后约1.9MB） | 0.60MB（压缩后约0.22MB） |
| 57KB/s 首次打开到可操作 | 约50秒，期间是空壳 | 约4秒，期间是载入遮罩 |
| 第二次打开（20KB/s） | 同首次 | 0.1秒 |
| 完全断网 | 打不开 | 0.2秒，头像与插图正常 |
| 下载中途断开 | 永远停在空壳 | 25秒后提示并给重新载入按钮 |

原有66项检查（`qa/paper` 下 `npm test`）全部通过。未做安卓真机验收。

## 以后发布要注意

- `assets/`、`sw.js` 必须和 `index.html` 一起上传。`.ghignore` 里没有忽略它们。
- 改过 `index.html` 或任何美术后，运行 `python3 tools/build-sw.py` 重新生成 `sw.js`（版本号跟内容走）。不跑也能更新页面，只是玩家要多开一次才看到新版。
- 新增或替换美术：把 webp 放进 `assets/art/`，文件名带新摘要，再改 `index.html` 里 `ART` 的路径。不要再把图片内嵌成 base64。
- `模拟券商.html` 现在同样依赖旁边的 `assets/`。
