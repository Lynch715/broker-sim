# 渝江证券：纸墨经营与十年任期

2026-10-11。本轮仅修改模拟券商，未发布线上版本。

## 界面与文案

纸白、青灰和铜金，支持浅色、暖色、夜读和跟随系统；宋体标题、经营账册、手机底部导航。18枚重新绘制的线性SVG图标和独立应用标志，没有emoji图标。设置页新增WeChat Lynchrrr。开场、操作说明、自营提示、经营页和结局文案改为自然的中文，保留必要数值和条件。

## 长期经营

普通模式可选36、72或120个月，默认120个月；旧档保留原期限，可主动延长。挑战模式保留原期限。后续市场周期、分类评级、投行候选持续运转。

六项长期建设：买方投顾团队、线上客户中心、机构服务台、骨干培养计划、成渝企业服务、家族财富办公室，分别在第1、2、3、4、5、7年开放，每项三级。建设占用资金、时间和精力；落成次月开始回款。经营方式会改变收入、费用、客户流入和风险，调整后至少执行三个月。界面预估和实际结算使用同一计算函数。

年度经营重点可自愿选择客户、盈利或内控目标。奖励是股东经营支持，不伪装成利润。客户资产与公司现金继续分账。

## 验证

- 17项引擎回归：新旧任期、迁移、建设、经营方式、结算分账、年度奖励、十年周期及挑战模式。
- 8项DOM交互：开局、联系方式、筹建、主题、经营方式、存档与渲染。
- 30个固定种子的经典三年模式与改动前逐项对比，月数、现金、客户资产、利润、评级及结局一致。
- 120个月受控测试用于验证后期系统可运行，并非自然通关或难度平衡证明。
- Codex应用内浏览器检查桌面和手机布局、设置、筹建、夜读、经营方式和月报；不代表真实手机设备验收。
